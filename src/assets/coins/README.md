# Coin marks

These are bundled brand assets, used to identify the currencies supported by the app.
They remain local at runtime; the app does not request logos from a third-party CDN.

`sources.json` records the original URL and project/catalog page for every image.
Most marks come from CoinPaprika's coin catalog. KevaCoin's mark comes from its
official website repository, and Talleo's from the project's GitHub organization.
The marks belong to their respective projects. They do not indicate endorsement.

Chukwa and Chukwa v2 are algorithm presets rather than currencies and use the app's
neutral processor icon. Unknown or unavailable marks use the same fallback.
