# AndroMiner Miner Binaries

This branch is generated by the Android Miner Binary workflow on `main`.

The app can download either binary:

```text
lib/arm64-v8a/tls/libxmrig.so
lib/arm64-v8a/notls/libxmrig.so
lib/armeabi-v7a/tls/libxmrig.so
lib/armeabi-v7a/notls/libxmrig.so
lib/<abi>/{tls,notls}/libxmrigcc.so
lib/<abi>/{tls,notls}/libxlarig.so
```

XMRigCC and XLArig are Experimental. The app downloads them only when its pinned hashes
cover the commit of this branch that it was built against.

`lib/<abi>/libxmrig.so` is kept as the TLS default for compatibility.

Source and build scripts live in the `miner-builder/` directory on the `main` branch.
